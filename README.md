# 💬 MERN Chat App

Real-time chat with auth, live status, and global state.

---

## ⚙️ Features  
- 🔐 JWT Auth  
- 💬 Live Messaging (Socket.IO)  
- 🟢 User Status  
- 🌍 Zustand State  
- ⚠️ Error Handling  

---

## 🛠️ Stack  
- ⚛️ React  
- 🧠 Zustand  
- 🟢 Node.js + Express  
- 📡 Socket.IO  
- 🍃 MongoDB
